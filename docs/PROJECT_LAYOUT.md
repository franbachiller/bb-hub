# BOT BB project layout

## Live folders

- `MODDED SWF/` - active SWF used by Fiddler. Keep `Kernel.swf` here.
- `controller-electron/` - BB Hub Electron source and packaged `dist/win-unpacked`.
- `punch_proxy/` - local proxy source and logs.
- `ring-board/` - ring-board tooling.
- `CONFIGS/` - Hub/timing/profile configuration history.
- `official_client/` - clean official client/decompiled references.
- `tools/` - FFDec and maintenance scripts.
- `RELEASES/` - zipped builds to copy to the VPS.

## Archive

- `_archive_20260602_cleanup/` - old experiments, backups, logs, alternate kernels, previous controllers, temporary exports, and unused loose files. Nothing was deleted.

## Current SWF

- `MODDED SWF/Kernel.swf` - current active Kernel.
- `MODDED SWF/Kernel.before_timing_target_fix_20260602_161502.swf` - immediate backup before the TIMING target fix.
